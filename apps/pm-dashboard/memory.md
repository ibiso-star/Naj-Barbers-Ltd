# Memory — Keel

Gotchas a fresh session shouldn't have to rediscover. Newest first.

### 2026-09-30 — Don't transform the dnd-kit DragOverlay's measured node

A `rotate()` on the overlay's direct child inflates its bounding box. Keyboard
collision detection (`sortableKeyboardCoordinates`) then treats cards in the
*same* column as being "to the right", and ArrowRight reorders within the
column instead of moving across. Put any tilt on an inner element.

### 2026-09-30 — Enter on a card must `preventDefault()`

The drawer is a native `<dialog>`, and it moves focus to its Close button on
open. If the Enter keydown that opened it isn't consumed, the same keypress
activates Close and the drawer shuts immediately. Mouse clicks aren't affected.

### 2026-09-30 — Demo writes persist before their simulated latency

`DemoRepository` delays responses by 120ms so pending states are visible. The
write happens *before* the delay. The other order loses a change if the user
reloads mid-request (an E2E test caught this). The provider also warns on
`beforeunload` while writes are pending.

### 2026-09-30 — `supabase/seed.sql` is generated; triggers are off while it runs

Edit `src/lib/data/seed.ts`, then run `npm run seed:generate`. The SQL sets
`session_replication_role = replica` so historical timestamps survive. That
also disables FK checks, which is why `supabase/tests/seed_integrity.sql`
re-checks every relationship. CI fails if `seed.sql` is out of sync.

### 2026-09-30 — Postgres applies SELECT policies to UPDATE targets

Weakening an UPDATE policy to `using (true)` did **not** expose other tenants'
rows in the mutation test, because the SELECT policy still hides them. Don't
read that as the UPDATE policy being redundant: it's the only thing stopping
writes if a SELECT policy is ever broadened.

### 2026-09-30 — supabase-js generics need `type` aliases, not interfaces

Row types declared as `interface` don't satisfy `Record<string, unknown>`, and
every query result silently becomes `never`. Keep `database.types.ts` rows as
`type` aliases.

### 2026-09-30 — `scripts/test-db.sh` needs PostgreSQL 15+ binaries

Composite FKs use `ON DELETE SET NULL (column)`, which is PG15+. When the
script runs as root (containers), it re-executes the server as the `postgres`
user, because `initdb` refuses to run as root.

### 2026-09-30 — Board positions lose precision after ~50 same-gap inserts

Dropping cards into the exact same slot repeatedly halves the gap each time.
Ties are broken by task number, so order stays stable, but a renumbering pass
is needed if users report cards "swapping" (`decisions.md` D-005).

### 2026-09-30 — Next 16: `proxy.ts`, async `params`, generated `PageProps`

`middleware.ts` is deprecated (renamed to `proxy.ts`, Node runtime only).
`params` and `searchParams` are promises. `PageProps` and `LayoutProps` are
global types generated by `next typegen` or `next build`, so run one before
`tsc` on a fresh clone.
