### 8.2 Anti-"vibe-coded" / anti-cliché checklist
The specific tells of low-effort AI-generated output — watch for these by name. Severities here are about how much each tell actually damages trust/functionality vs. pure taste. **Checked = verified absent.** Unlike every other section, these items name the fault itself, not the control — ticking the box means you looked and confirmed this tell isn't present, not that it is. These decisions are made in section 3, not here — this section verifies section 3's choices held, it doesn't make them.

### 8.4 Accessibility baseline
- [x] 🔴 [A11Y-001] Target conformance level and standard version stated (normally WCAG 2.2 AA for public web/mobile); automated and representative manual checks recorded for the critical journeys — a vague "WCAG AA" claim with no version or check method tends to get asserted rather than verified
- [x] 🟡 [A11Y-002] Full keyboard navigation on all interactive elements
- [ ] 🟡 [A11Y-003] Meaningful alternative text for informative images; empty `alt=""` for purely decorative images — not the same rule applied blindly to both
- [x] 🟡 [A11Y-004] Semantic HTML / proper ARIA labeling, not div-soup


### 8.5 Performance baseline
- [ ] 🟡 [PERF-001] Performance budgets and measurement conditions are stated for the critical pages (device class, connection, test tool, and target Core Web Vitals where applicable), then actually checked before release — not assumed fine
- [ ] 🟡 [PERF-002] Images served in modern formats, appropriately sized/lazy-loaded
- [ ] 🟡 [PERF-003] Caching strategy defined for anything expensive to compute or fetch repeatedly
- [ ] 🟢 [PERF-004] Stateless/serverless functions considered as one architecture option among others where they genuinely fit — neither stateless nor stateful is inherently better; pick based on the actual workload


### 8.10 SEO & discoverability
- [ ] 🟡 [SEO-001] Meta titles & descriptions on every page
- [ ] 🟡 [SEO-002] XML sitemap generated and submitted to Google Search Console
- [x] 🟡 [SEO-003] Favicon present
- [ ] 🟢 [SEO-004] Optimize copy to rank for the keywords that actually matter for this project
